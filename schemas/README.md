# Shared schemas

**Status:** Schema definitions have not been approved. This directory is part of the complete shared foundation for every role.

The proposed names in the v0.6 blueprint cover civic records, jurisdiction, interest profile, source evidence, classifier and relevance results, connector and model manifests, evidence packs, role and module manifests, candidates, and releases. Define fields from agreed producer and consumer examples before adding JSON Schema files. Each schema needs a version, validation tests with valid and invalid fixtures, compatibility rules, and an owner. A filename alone does not establish an interface.

See [schema governance](../governance/SCHEMA_VERSIONING.md) and [interface planning](../docs/api-contracts/README.md).
