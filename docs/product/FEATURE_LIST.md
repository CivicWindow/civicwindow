# Feature inventory

**Status:** Proposed feature categories from the CivicWindow pitch. Presence in the source tree is not implementation evidence.

## Category A — core

1. Private onboarding without mandatory accounts
2. Manual selection of supported jurisdictions
3. Multi-jurisdiction ingestion through validated connectors
4. Local persistence and offline search of downloaded records
5. Locally stored interest profiles
6. Custom-trained or fine-tuned civic topic classification
7. On-device semantic relevance matching
8. Evidence-linked results and official source navigation
9. Optional notifications after retrieval and matching, with refresh status/manual refresh
10. Portable Evidence Pack export

## Category B — growth

11. Additional jurisdictions and connectors
12. Structured entity, action and deadline extraction
13. Document change detection and version history
14. Advanced PDF agenda processing and OCR
15. Advanced geographic and entity filtering

## Category C — enhancement

16. Specialized on-device reasoning model
17. Multilingual classification and discovery
18. Community-contributed connector framework
19. Enhanced evidence reporting and comparisons

The 14 proposed feature/source areas in `modules/` are an engineering decomposition, not a one-to-one count of these 19 product features or a guarantee of 14 build modules. Track implemented status with linked tickets and evidence once project tracking exists.
