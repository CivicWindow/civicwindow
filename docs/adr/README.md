# Architecture decision records

**Status:** ADR-0001 to ADR-0007 are Accepted (2026-11-10). A record is Accepted only when its Status line says so.

Use one numbered record per consequential decision: context, options, decision, rationale, affected modules/contracts, owner, date, and supersession link. A proposed option is not an approved decision.

Each record follows the [MADR](https://adr.github.io/madr/) (Markdown Architectural Decision Records) layout and carries these fields: Status, Date, Decision-makers, Owner, and the supersession links, then Context and problem statement, Considered options, Decision outcome, Consequences, Affected modules and contracts, Enforcement, and More information.
