# Candidate promotion

**Status:** Policy; no publishing or integration machinery exists.

An accepted module candidate records exact source revision, selected tickets/prerequisites, contract versions, resolved dependencies, toolchain and model/asset identities, artifact digest, checks and review. A branch tip with unrelated accepted tickets is not an A-only candidate. Changed selection requires a new build and evidence.

Select the needed candidate/source closure, prepare integration against current `dev`, resolve conflicts and validate the real assembled result. Review the exact proposed source and record the integration revision. A fixed release candidate is a later stage with separate validation; publishing a development package does not approve production.
